Install

01

Download the APK

Grab the latest build from the releases page. Your phone will ask you to allow installs from your browser or files app.

APK
02

Sign in

Choose Last.fm or Libre.fm. If the build has no API key baked in, Last.fm asks you to create a free API account first. It takes a minute.

A
03

Allow notification access

That is the only way Android lets an app see what is playing. larp.fm does not read or store your notifications.

ON
TIP

On Android 13+, if the notification access switch is greyed out, open App info and use Allow restricted settings, then try again.
